# Sitio Docente en Quarto

Proyecto de website académico para mostrar cursos y una sección de futuros notebooks.

## Requisitos

- [Quarto CLI](https://quarto.org/docs/get-started/)

## Ejecutar en local

```bash
cd /home/jorge/teaching-site/sitio-docente
quarto preview
```

## Generar sitio estático

```bash
cd /home/jorge/teaching-site/sitio-docente
quarto render
```

El resultado se genera en la carpeta `_site/`.
